# 🤖📄 Docsy IA

Docsy IA es una aplicación basada en inteligencia artificial que permite cargar documentos y analizarlos mediante un chatbot interactivo, facilitando la consulta y comprensión del contenido de los archivos.

## 🚀 Características principales
- Carga de documentos (PDF, Word, etc.)
- Escaneo y análisis automático del contenido
- Chatbot con inteligencia artificial
- Consultas en lenguaje natural
- Respuestas basadas únicamente en el documento cargado

## 🎯 Objetivo del proyecto
Desarrollar una herramienta inteligente que permita interactuar con documentos de forma eficiente, reduciendo el tiempo de búsqueda de información y mejorando la experiencia del usuario mediante el uso de IA.
